# v0.3.0

*Release date: August 18, 2026*

---

## Added

- **A real home page.** ThirtyTutors now opens on an actual home page on every launch, instead of forcing a profile picker every time - your last-active profile just stays "logged in," shown in the new profile menu (top right) so you can jump straight back in. Profile creation moved to its own **/get-started** page, reached from there or from the profile picker's "Add profile" tile.

- **Test Yourself - a standalone quiz mode.** Every quiz item the tutor has already asked you, across a whole conversation, can now be replayed as one quick round on its own dedicated page - reachable from a new icon on each conversation row in your profile. Filter by All time / Today / Last 7 days / Last 30 days, get shuffled and deduplicated questions (no repeats of the same word), and redo the round as many times as you want. Answering still feeds the same spaced-repetition tracking a live quiz does.

- **A Stats tab.** See your day streak, total hours studied, and languages practiced at a glance, plus a per-language breakdown: words mastered (with a progress bar toward the next 50-word milestone), quiz accuracy, perfect-quiz badges, and Test Yourself rounds completed. Crossing a milestone (every 50 words mastered per language, or a streak of 3/7/14/30+ days) now shows up as a notification in the top-bar bell, once.

- **Profile backup.** Export a full backup of one profile - every conversation, every quiz, and its voice enrollment - as a single zip file, and import it back later (on this machine or a different one). Optional automatic backups can also run in the background on a schedule you set (daily/every 3 days/weekly/monthly), checked once per app launch.

- **Redesigned top bar and Settings.** A permanent profile-switcher icon sits next to Home for jumping between profiles at any time. The profile menu (top right) now opens Settings from anywhere in the app, not just mid-conversation. Theme is now a three-way System / Light / Dark choice in Settings → General (System follows your OS setting live), replacing the old single toggle button - and Light is now the default for anyone who hasn't picked a theme yet.
